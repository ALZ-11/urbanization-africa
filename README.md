# Urbanization in Africa - Big Data Analysis

## Description
This project focuses on analyzing urbanization trends and infrastructure in Africa. It uses SPARQL queries to extract data from Wikidata and Python for data analysis and visualization.

## Project Structure
- `FS_BigData_UrbanisationAfrique.pdf`: Project report.
- `Analyse de données/`:
  - `visualisations.ipynb`: Jupyter notebook containing data visualizations.
  - `requetes_SPARQL.txt`: SPARQL queries used to fetch data from Wikidata.
  - `*.csv`: Datasets extracted from Wikidata.

## Setup
To run the analysis:
1. Ensure you have Python installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `visualisations.ipynb` in Jupyter or Google Colab.
